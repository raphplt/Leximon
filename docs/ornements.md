# Ornements anciens

`packages/tokens/scripts/bake_ornaments.py`, à partir de `rnd/ornements/sources.json`, qui
donne le détail de chaque vérification. Les ornements dessinés par nous sont dans
`packages/tokens/src/ornaments.ts`.
